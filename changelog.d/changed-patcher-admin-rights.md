- `PatchD2File.exe` and `RestoreD2File.exe` ask for administrator rights when the
  Diablo II folder needs them, such as under Program Files, and tell you when
  Diablo II is still running. A `Game.exe` that is already patched (or already
  restored) is reported right away, even while Diablo II runs. Scripts can name
  the folder with `--dir` and run them silently with `--silent`; the readme lists
  the exit codes.
