- **Leaner long TCP/IP hosting.** On Diablo II 1.14d, a TCP/IP host frees the
  stash data it prepared for a player as soon as that player has left the game.
  A host that runs for hours while players come and go saves at least 32 KB of
  memory per departure, more with big stashes. The host needs PlugY4Kolbot for
  this.
